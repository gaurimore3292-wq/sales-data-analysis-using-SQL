Sales Data Analysis Using SQL
Project Overview
This project analyzes sales data using SQL Server. The dataset contains 500 sales orders.
Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL
Analysis Performed
- Total Sales Analysis
- Order Status Analysis
- City-wise Sales Analysis
- Product-wise Sales Analysis
- Payment Mode Analysis
- Category-wise Sales Analysis
- Monthly Sales Analysis
- Product Quantity Analysis
- Customer-wise Sales Analysis
- Average Sales per Order
- Top 5 Customers Analysis
Key Insights
- Total Orders: 500
- Total Sales: ₹1,95,61,200
- Completed Orders: 335 (67%)
- Highest Sales City: Nashik
- Highest Orders City: Pune
- Top-selling Product: Laptop
- Most Used Payment Mode: UPI
- Highest Sales Category: Electronics
- Highest Sales Customer: Sneha
- Average Sales per Order: ₹39,122
